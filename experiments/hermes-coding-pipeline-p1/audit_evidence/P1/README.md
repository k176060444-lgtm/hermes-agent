# Independent code audit submissions

Only independent review reports should be added under `round-001/`, `round-002/`, etc. Each review pins the exact source commit. Preserve prior rounds append-only. The auditor must not change source code while committing findings.

Each new round contains `AUDIT_REPORT.md`, `FINDINGS.json`, `TEST_RESULTS.txt`, and `SCOPE.json`.

Severity BLOCKER/HIGH/MEDIUM/LOW; distinguish reproduced bugs from unverified integration requirements. Do not represent offline fixtures as real Agent execution or actual Debian physical review.
